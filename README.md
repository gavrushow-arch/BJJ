# AvagbeChamps Admin

Нативный пульт администратора соревнований BJJ для iPhone и iPad. SwiftUI, SwiftData, JavaScriptCore; iOS/iPadOS 17+. Версия приложения 2.0.1, build 2.

Спортсмены и родители используют Telegram-бота **@AvagbeChampsbot**. Подтверждённые данные хранятся в Google Таблицах; Apps Script обслуживает API и Telegram. В этом репозитории размещено iOS-приложение.

## Открыть на Mac

```sh
git clone https://github.com/gavrushow-arch/BJJ.git
cd BJJ
open AvagbeChampsAdmin.xcodeproj
```

1. Установите Xcode с SDK iOS 17 или новее и iOS Simulator.
2. Выберите схему **AvagbeChampsAdmin** и симулятор iPhone или iPad.
3. **⌘U** запускает тесты, **⌘R** — приложение.
4. Для установки на устройство выберите свой Team в **Signing & Capabilities**. При необходимости замените bundle ID `com.avagbe.champsadmin` на доступный в вашем аккаунте.

Общий JavaScript-движок уже включён в ресурсы; Node.js для открытия и сборки не нужен. При изменении состава файлов проект можно пересоздать командой `node generate-project.cjs`.

## Подключение к боту

Адрес опубликованного Apps Script задан по умолчанию. Нажмите **«Подключить устройство»**, откройте Telegram, подтвердите устройство кнопкой от имени действующего администратора и вернитесь в приложение.

Адрес можно изменить на экране входа или через **Настройки → Google Apps Script → Изменить адрес скрипта**. Используется основной HTTPS URL, заканчивающийся на `/exec`, без `?key` и других параметров. Есть возврат адреса по умолчанию.

При смене сервера закрывается прежняя сессия и очищается локальная копия. Неподтверждённую команду сначала нужно проверить на исходном сервере. Токен бота и Google-доступ в приложение не вводятся: сессия устройства хранится в Keychain, локальные данные — SwiftData.

## Возможности

- Участники, клубы, возрастные и весовые категории, пояса и объединения.
- Индивидуальные круговые/олимпийские системы, предпросмотр сеток и результаты.
- 1–3 ковра, длительность, отдых, порядок, черновик и публикация расписания, фактическое время и задержки.
- Завершение с итогами или без подведения итогов, архив.
- Версии объектов, защита от повторных команд, синхронизация и отзыв устройств.
- Сохранённая копия без сети; административная запись требует подключения.

## Автоматическая проверка

Workflow **iOS build and tests** собирает приложение и запускает XCTest на доступном iPhone Simulator без подписи. Результаты и журнал тестов доступны во вкладке **Actions**.

Для ручного запуска замените имя симулятора на установленное:

```sh
xcodebuild test \
  -project AvagbeChampsAdmin.xcodeproj \
  -scheme AvagbeChampsAdmin \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  CODE_SIGNING_ALLOWED=NO
```

До реального турнира нужна проверка на устройствах: вход через Telegram, работа нескольких администраторов, потеря сети/ответа, отзыв доступа, совпадение жеребьёвки и пересчёт расписания. Сборка в CI не заменяет эту приёмку.

## Распространение

Для TestFlight/App Store нужны Apple Developer account, подпись, App Store Connect, политика конфиденциальности и декларация данных. Публикация исходников в GitHub не устанавливает приложение на телефон и не выпускает его в TestFlight.
